# Familiar Desktop v0.1.1-rc.3

A test build for the next round of XPS acceptance before final v0.1.1.

- Installation retries shell refresh while Omarchy reloads the plugin, avoiding the transient “Target not found” failure. Persistent failures still stop setup.
- Backend and Hyprbars downloads are checked against SHA-256 digests committed in the reviewed source. Replacing release assets and their accompanying checksums together no longer passes that check.
- Candidate installation fetches its exact source snapshot and verifies both bundled binaries against its committed digests before executing the backend. Release packaging also rejects rebuilt bytes that differ from those pins.
- Includes RC.2’s opt-in border resizing, Floating/Tiling for existing and new eligible windows, Command editing aliases, shortcut labels, trackpad gestures and smoother dock cycling.

## Install for testing

Download `familiar-v0.1.1-rc.3-linux-x86_64.zip` and its `.sha256` file into one directory:

```bash
sha256sum --check familiar-v0.1.1-rc.3-linux-x86_64.zip.sha256
mkdir familiar-v0.1.1-rc.3
unzip familiar-v0.1.1-rc.3-linux-x86_64.zip -d familiar-v0.1.1-rc.3
cd familiar-v0.1.1-rc.3
bash install-candidate.sh windows
omarchy restart shell
```

Use `mac` for left-side controls. For repair, rerun this candidate installer. Settings repair and standalone install.sh still target unpublished final v0.1.1 assets.

The adjacent ZIP checksum provides transport integrity, not independent authentication of the installer. Use a separately verified ZIP digest when available. Once trusted, the candidate installer obtains its binary pins from the exact Git snapshot. This is not a claim of signatures or marketplace approval.

Supported target: Linux x86_64, Omarchy Quattro, Hyprland 0.56.2 commit `efb50993780079460b0cbed1363e2166a2de1d9f`, ABI `efb50993780079460b0cbed1363e2166a2de1d9f_aq_0.15_hu_0.14_hg_0.5_hc_0.1_hlg_0.6`. Other ABIs are refused.

## Acceptance still needed

Portable tests, installer fixtures, coordinated binary/checksum substitution regressions and release packaging run in CI. Real backend and Hyprbars downloads have also been exercised through the changed installers; compositor loading is not covered by that test.

Live XPS install/update, resizing, mode switching, dock restore, shortcuts, gestures, persistence, mixed scaling, multiple monitors and removal still require testing. Follow XPS-TEST.md in the bundle. Existing gesture conflicts can reject preferences; custom terminal classes need review before Command aliases are enabled.

Remove using:

```bash
bash ~/.config/omarchy/plugins/io.github.tcballard.familiar-desktop/uninstall.sh
```

Removal resets owned compositor preferences and restores tracked windows, retaining personal settings and backups. This is a prerelease; v0.1.0 remains the latest stable release. No existing tag or asset is replaced.
