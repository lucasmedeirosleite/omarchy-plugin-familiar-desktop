# Familiar Desktop v0.1.1 — in preparation

Opening another window should not have to squeeze the one you are using.

**Windows → Floating / Tiling** now switches eligible existing windows across regular workspaces and sets the policy for new app windows. Floating windows overlap, so opening another terminal does not split them. Tiling uses the current Hyprland layout. Fullscreen, pinned, grouped and hidden windows are skipped. Choose **Use configuration** to remove the future-window preference without moving existing windows. This is native floating placement, not a new automatic cascade layout.

Dock activation now focuses the selected window and moves the pointer to its centre, using current compositor geometry after restoration. Minimising does not move the pointer to a sibling. Right-click an app and choose a named window to focus or restore that exact window; **New Window** remains a separate app-launch action, subject to the application's own launch behaviour.

Minimise keeps the application running on a hidden workspace. Its dock entry remains available; restoring brings it to the current workspace. There is no animation of the window shrinking into the dock, and unsaved work remains in the running application.

The installer and Settings repair are separated. Release CI generates a bootstrap pinned to the final full source SHA. Settings repair uses the installed checkout and versioned binary installers without fetching or checking out a remote tag. Existing v0.1.0 release assets and tags stay unchanged.

Final v0.1.1 is not published. Prereleases are for XPS testing; final acceptance, exact source identity and public asset verification remain release gates. Further user feedback may change the candidate.

## Completed feedback for rc.2

- Mouse resizing: an explicit Windows preference enables Hyprland border/corner
  dragging with a 15-pixel grab area and resize cursor. No held modifier is needed.
- Desktop mode: Floating/Tiling updates existing eligible windows across regular
  workspaces and persists the choice for newly opened windows. Fullscreen, pinned,
  hidden and grouped windows are skipped. Tiling uses the existing Hyprland layout
  and shortcuts. A failed individual action is reported; pressing the mode again
  retries it. This is not an atomic restore of prior tiling order or geometry.
- Command editing: a separate opt-in preference replaces Super+C/V/X/A/Z and
  Super+Shift+Z with standard app editing shortcuts. Known terminals use
  Ctrl+Shift+C/V, with other aliases passed through. It is not a global key swap
  or universal macOS shortcut emulation; custom terminal classes need review.
- Familiar remains an integrated plugin. A separate dock package or dock-only
  installer is explicitly out of scope at the owner's request.

Configuration changes use guarded owned files, exact-content checks, backups,
reload verification and rollback. Reset/uninstall restores the user's original
configuration; simply disabling the shell plugin retains compositor preferences.
No new privileged operation, input daemon or network dependency is introduced.
