# Familiar Desktop v0.1.1-rc.1

The first v0.1.1 test build is ready. This collects the window behaviour and installer changes before the next round of feedback.

- **Keep your tiles the same size.** Choose Windows → Floating to make newly opened windows overlap instead of splitting the tiled layout. This includes Super+Enter terminals. Existing windows keep their layout; Use configuration removes the preference.
- **Land in the right window.** Dock activation now focuses the selected window and centres the pointer using its current geometry. Right-click an app to choose a named window. New Window remains a separate action.
- **Repair the installed version.** Settings repair no longer fetches source through a tag. Release installers carry the exact built source SHA.

Minimise keeps the app running on a hidden workspace. Its dock entry restores it to the current workspace; there is no shrink-into-taskbar animation.

## Try this RC

Download the `familiar-v0.1.1-rc.1-linux-x86_64.zip` asset and its `.sha256` file into the same directory. From that directory:

```bash
sha256sum --check familiar-v0.1.1-rc.1-linux-x86_64.zip.sha256
mkdir familiar-v0.1.1-rc.1
unzip familiar-v0.1.1-rc.1-linux-x86_64.zip -d familiar-v0.1.1-rc.1
cd familiar-v0.1.1-rc.1
bash install-candidate.sh windows
```

Use `mac` instead of `windows` for Mac-style controls. The bundle verifies its files and installs its exact source commit. Read `XPS-TEST.md` and `RELEASE-0.1.1.md` inside the bundle. Re-run the candidate installer for RC repair: the Settings repair command and standalone `install.sh` target final v0.1.1 assets, which are not published yet.

Supported target: Linux x86_64 on Omarchy Quattro with Hyprland 0.56.2, commit `efb50993780079460b0cbed1363e2166a2de1d9f`, ABI `efb50993780079460b0cbed1363e2166a2de1d9f_aq_0.15_hu_0.14_hg_0.5_hc_0.1_hlg_0.6`. Other ABIs are refused.

Rust, Lua, QML, installer, cleanup and release-build checks pass before this RC is published. The new floating preference and pointer placement still need live XPS and multi-monitor/scaling testing. This is a prerelease for that testing, not the final v0.1.1 or a marketplace approval. More feedback is still being collected. Checksums beside downloads are not independent publisher attestations.

Remove using the installed plugin's `uninstall.sh`; restore minimised windows first if prompted. Personal preferences and recovery backups are retained.
