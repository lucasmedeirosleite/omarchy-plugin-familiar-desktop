# Familiar v0.1.0

5 October 2026.

Familiar gives Omarchy a few familiar places to click: a dock, visible window controls and settings you can open from the bar.

- **Find the right window.** Open an app, choose one of its windows by name, bring it to your workspace or arrange it on screen.
- **Make room, then get back to work.** Show Desktop hides eligible windows; Restore brings them back. A recovery journal keeps track across shell reloads.
- **Choose what feels comfortable.** General, Windows and Mac starting layouts share your pins. Put the dock at the bottom, left or right, or keep automatic placement. Your position choice survives layout changes. Dock and title-bar sizing can be adjusted independently.
- **Keep the everyday controls close.** Centred settings, active keyboard-shortcut help, optional Home/Downloads/Bin shortcuts, and separate Quit and confirmed Force Quit actions.
- **Let Caps Lock mean Caps Lock.** Choose Normal Caps Lock, Compose or Use configuration. Nothing changes until you choose; unrelated keyboard options are preserved.

Installation uses prebuilt Linux x86_64 components. No Cargo, Clippy, Hyprpm or Hyprland source build on your machine. Window controls require the exact Hyprland ABI listed in the README; unsupported versions stop before configuration changes.

This release focuses on the desktop. The curated Open/Install app collection is planned for v0.2.0, after individual package checks. Paint, Notepad and Task Manager remain separate projects; installed applications continue to work through the dock.

For removal, run the installed `uninstall.sh`. It restores journalled windows, checks for remaining minimised windows, disables Familiar, resets Caps Lock and removes the owned title-bar hook before deleting the plugin. Failed cleanup stops removal. Settings, pins and backups are retained; see the rollback guide for legacy-build limits.

**Compatibility and testing:** Linux x86_64 on Omarchy Quattro, with prebuilt window controls for Hyprland 0.56.2 commit `efb50993780079460b0cbed1363e2166a2de1d9f`, ABI `efb50993780079460b0cbed1363e2166a2de1d9f_aq_0.15_hu_0.14_hg_0.5_hc_0.1_hlg_0.6`. The maintainer tested rc.5 (`377f8823c1b8a013131d75d614339bf569c9a68e`) on an XPS and approved it for release. Runtime source is unchanged; final preparation updates documentation and tag automation. Portable Rust, Lua 5.4/5.5, QML and installer fixtures passed, as did the static release build. This is not a claim of exhaustive monitor, scaling or application coverage. The exact installed Omarchy revision and a per-step fresh-profile installation/removal record were not captured in the sign-off.

Install with the versioned command in the README. If something breaks, [open a bug report](https://github.com/tcballard/omarchy-plugin-familiar-desktop/issues/new/choose) with the version, reproduction steps and a screenshot or error text.
