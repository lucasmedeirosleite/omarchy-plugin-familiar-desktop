# Familiar Desktop v0.0.6 — find and arrange your windows

Early preview for Omarchy Quattro on Linux x86_64.

- Select a window by name, see its workspace or minimised status, and use **Go to / restore** or **Bring here** to recover it.
- Arrange the selected window: left/right half, centre, maximise, floating, tiling or next monitor. Half-screen and centre actions make that window floating.
- Optionally add **Home, Downloads and Bin** to the dock. Shortcuts default to off; Bin opens the installed file manager and never empties the bin.
- Window selection follows its address when the list reorders. Closed targets are rejected and action failures are shown.

## Install or update after publication

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/tcballard/omarchy-plugin-familiar-desktop/v0.0.6/install.sh) mac
```

Use `windows` instead of `mac` for controls on the right. Wait for the release binaries and SHA256SUMS to be attached before installing. The installer downloads checksum-verified prebuilt components; no Cargo, Rustup, Clippy, Hyprpm or Hyprland source checkout is required.

Window controls retain the supported Hyprland 0.56.2 ABI documented in the README. Unsupported ABIs stop with an error, without a source-build fallback. File shortcuts require `gio` and, for Downloads, `xdg-user-dir`, plus an installed file manager supporting the requested location.

## Verification and limitations

The feature candidate passed portable checks and release-binary CI. Backend fixtures cover explicit window targeting, missing targets, scaled/rotated work areas and file-opening failures. Isolated Qt checks exercise selection after reordering and window removal. The release candidate must also pass its own version-aligned CI before publication.

**Not live-validated:** actual Hyprland movement, application size constraints, focus/dismissal, monitor hotplug and switching, and installed-file-manager behaviour. Fresh installation, update/removal and shell lifecycle still need on-device acceptance. Rendered QML evidence uses substituted shell/window data and is not a live Omarchy screenshot. This release is a preview, not a marketplace-readiness claim.

Preferences are retained on removal. Follow the README cleanup command before removing the plugin to remove Familiar-owned title-bar configuration.
