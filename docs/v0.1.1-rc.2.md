# Familiar Desktop v0.1.1-rc.2

The next test build brings the rest of the desktop feedback together.

- **Resize with the mouse.** Enable border dragging, then drag a window edge or corner without holding a modifier.
- **Switch how windows behave.** Floating and Tiling now act on eligible existing windows and set the mode for new ones. Fullscreen, pinned, grouped and hidden windows are skipped; tiling uses your current Hyprland layout and shortcuts.
- **Use Command for editing.** An opt-in setting adds Command copy, paste, cut, select all, undo and redo. Known terminals use Ctrl+Shift+C/V for copy/paste. The setting replaces the listed Super bindings until reset; it is not a global key swap.
- **Choose familiar labels and trackpad gestures.** Command/Option/Control labels, three-finger workspace swipes, four-finger Show Desktop/Restore and smoother dock window cycling are included.

Title bars remain part of Familiar, with optional Mac/Windows controls. Familiar stays one integrated plugin.

## Try this RC

Download `familiar-v0.1.1-rc.2-linux-x86_64.zip` and its `.sha256` file into the same directory:

```bash
sha256sum --check familiar-v0.1.1-rc.2-linux-x86_64.zip.sha256
mkdir familiar-v0.1.1-rc.2
unzip familiar-v0.1.1-rc.2-linux-x86_64.zip -d familiar-v0.1.1-rc.2
cd familiar-v0.1.1-rc.2
bash install-candidate.sh windows
```

Use `mac` for Mac-style title bars. Re-run the candidate installer for RC repair;
Settings repair and standalone `install.sh` target unpublished final v0.1.1 assets.
The bundle installs its exact built source and checks its files. Checksums beside
the download are not independent publisher attestations.

Supported target: Linux x86_64, Omarchy Quattro, Hyprland 0.56.2 commit
`efb50993780079460b0cbed1363e2166a2de1d9f`, ABI
`efb50993780079460b0cbed1363e2166a2de1d9f_aq_0.15_hu_0.14_hg_0.5_hc_0.1_hlg_0.6`.
Other ABIs are refused.

## Test before enabling everything

Preferences are opt-in. Existing gesture conflicts can reject a choice; use the
separate desktop/workspace groups. Two-finger taps depend on system right-click
settings. Custom terminal classes need review before enabling Command aliases.
Mode switching reports skipped/failed windows; retry finishes partial changes.
Use configuration removes owned overrides without reconstructing old window
geometry. Disabling the shell plugin alone retains compositor preferences.

Automated checks run before publication. Live XPS resizing, gestures, shortcut
handling, mixed scaling and multi-monitor acceptance remain outstanding. Follow
`XPS-TEST.md` and `RELEASE-0.1.1.md`; this is a test prerelease, not final v0.1.1.
Remove using the installed plugin’s `uninstall.sh`, which restores tracked
windows and removes owned preferences while retaining backups.
